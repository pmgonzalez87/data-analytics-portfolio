## 🌟 Featured Projects

### 1. [A/B Testing & Statistical Hypothesis Analysis](./capstone-projects/A_B_Testing_GonzalezP.ipynb)
* **Goal:** Evaluated e-commerce site redesign impact on user engagement and conversion rates.
* **Techniques:** Parametric statistical tests (Two-sample Independent t-Test), Levene's test for variance, Shapiro-Wilk test for normality, and exploratory data analysis (`pandas`, `scipy.stats`, `seaborn`).
* **Key Finding:** Identified a statistically significant increase in conversions for the experimental variant ($p < 0.05$).

### 2. [Interactive CLI Calculator & Geometry Solver](./capstone-projects/Calculator_2_0.ipynb)
* **Goal:** Designed an interactive Python utility for routine math and geometric calculations.
* **Techniques:** Control flow, function modularity, string styling (`pyfiglet`, `termcolor`), and defensive error handling (`try/except`).
